# SEEM3410 Hospital Outpatient Clinic

Independent Python discrete-event simulation and reproducible staffing analysis for the supplied **synthetic** hospital dataset. Primary question, target and policies are fixed in `config.py`: minimize illustrative scheduled doctor cost among 2/3/4 doctors while meeting mean run-level P90<=15 minutes. Original-input replay, fresh empirical input and Poisson sensitivity are separate.

## Run

Python 3.10+ (tested version recorded in outputs/reproducibility/environment.json). From the project folder:

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -q
python run_all.py --smoke
python run_all.py
```

No network service is required after dependencies are installed. Full execution regenerates `outputs/` from empty, checks all phases, creates report/figures and portable presentation materials, builds the ZIP and tests a full run from its extracted copy. It also compares all deterministic CSV/calibration hashes. Runtime is recorded, not assumed. `python run_all.py --no-package` executes all computations/report generation without recursively packaging; this is the command used in the extraction check. The default full run preserves the unchanged raw ZIP, source documents and separately authored editable PPTX. Tests also work before outputs exist.

## Configuration and methods

`config.py`: seed 3410, fresh confirmation 93410, 50 replications, 200 patients, peak boundary 240 min, target 15 (also 10/20/30), doctor wage 100 units/hour, schedule 1080 min, numerical resolution 1e-9 min. Default pharmacy 1 counter; 2 only as performance sensitivity. All cost values are assumptions. Do not change the primary model after inspecting results. Course mappings, metrics, actual pseudocode and assumptions are in `docs/`.

Four independent RNG streams per replication: arrival, priority, consultation, pharmacy. Save uniforms and seed ledger; input hashes verify CRN across staffing. Priority 3 highest, non-preemptive, FCFS within class; arrival events before tied completions. Pharmacy tie is(doctor end,patientID). Staff remain available to complete all 200 patients. There is no warm-up, closing-time censoring, abandonment or blocking.

## Interpretation and known limits

P90 uses NumPy linear quantile on all 200 patients, then averages run estimates. CI sample size is independent runs, not pooled patients. Zero-width observed intervals are not universal guarantees. Confidence intervals quantify Monte Carlo uncertainty conditional on calibrated synthetic inputs. Empirical PMFs omit unobserved tails; independence and previous-clock conditioning are assumptions. Poisson changes arrival variability and can change staffing choice. Changing a common positive wage cannot change scheduled-cost ranking. Busy-minute overtime is not payroll. Slower arrivals can extend the fixed cohort past the assumed schedule; these runs are flagged and never censored. Target-straddling cells in decision_matrix.csv remain inconclusive; they are not silently resolved by selective runs.

Human review remains necessary for synthetic-data acceptability, model/cost/metric assumptions, team details, AI disclosure, code understanding, report proofreading, course-platform submission and presentation date/rehearsal. Software does not mark submission or rehearsal complete.
