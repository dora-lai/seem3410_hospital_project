1 M/M/ 1 Queue Simulation in Python
Recap: Discrete-event simulation (DES) logic (Week 3, slide 25)
Initialize once
• Set the clock , initial state , statistics , and ending condition .
• Put the initial events into the future-event list (FEL) .
Repeat the event loop
1. Check the ending condition; select the earliest event from the FEL .
2. Accumulate statistics over the elapsed interval using the old state .
3. Advance the clock to the event time.
4. Remove the event and run its event routine : update state, customer records,
and the FEL; draw inputs as needed.
Finish: Compute performance measures from the statistics.

Is increasing the number of replications R enough?
If the target is estimating steady-state performance, then NO.
• Every replication restarts the system empty , which suffers from an
initialization (transient) bias relative to steady state.
• While increasing R estimates the performance of the empty-start system more
accurately, it does not remove this transient bias.
• To address this, we use warm-up deletion : simulate the system from t = 0 ,
but estimate its performance using only data collected over [ t 0 , T ) , where
0 < t 0 < T .
• The initial [0 , t 0 ) serves as the warm-up period : the system evolves as usual,
but data from this period are excluded from the performance estimates.
When is warm-up not needed? If the real system starts empty each day and the
target is that finite day’s performance , then there is no transient bias.

Week 4 summary
• Python implements the DES event loop. Initialize once, then advance the
clock and execute the earliest FEL event.
• Independent runs estimate expected performance. Repeat the simulation
function with independent random inputs and average its outputs.
• Warm-up deletion reduces initialization bias. Keep the system running, but
measure only the production window. Choose warm-up using pilot
comparisons at fixed production length.
• Confidence intervals quantify simulation uncertainty. Under a normal
approximation, 95% confidence interval for the performance to be estimated
can be constructed as Y R ± 1 . 96 s Y /R .
• Variance-reduction methods: antithetic variates and control variates.
Antithetic variates pair runs with negatively correlated outputs. Control
variates adjust outputs using a variable with known mean.
• Importance sampling improves rare-event estimation. Draw from a different
distribution and weight outputs by f /g to retain the original target.
